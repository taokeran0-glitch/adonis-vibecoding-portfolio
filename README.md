# ADONIS — 游戏增长与内容运营交互式作品集

这是一份由原 12 页 PowerPoint 转化而来的单页交互式作品集。网站把静态履历重组为可探索的招聘叙事：先建立个人定位，再展示内容增长案例、视觉创作、游戏经历与 Vibe Coding 方法论工具。

## 设计方向

- 视觉语言：Minimal Zine Poster v0.1
- 基础色：旧纸米白、炭黑、钴蓝
- 辅助色：番茄红、酸性绿
- 排版：中文宋体感标题、拉丁衬线斜体、等宽档案标签
- 原则：大留白、纸张纹理、编辑式网格、真实证据优先

## 页面与交互

- `INDEX`：个人定位、核心数据与生成式 zine 首图
- `WORK`：小红书绘画账号增长与商业化案例，支持打开真实数据证据层
- `VISUAL ARCHIVE`：绘画、摄影、zine / 剪辑三类作品筛选与灯箱查看
- `PLAYER ARCHIVE`：14 个游戏一级品类切换，展示对应游戏清单与体验判断
- `LAB`：输入“社会痛点 + 反差设置 + 情绪叙事”，即时生成内容角度并复制结果
- `ABOUT`：下载原作品集 PDF 与游戏运营简历

网站包含吸顶导航、阅读进度、当前章节状态、响应式菜单、键盘语义和 `prefers-reduced-motion` 适配。

### 交互增强

- WebGL 粒子文字开屏：`ADONIS` 从全屏信号粒子聚合成形，支持鼠标扰动、自动回弹、跳过与键盘进入
- 首屏标题、章节内容与作品网格按阅读位置渐进揭示
- 首屏档案海报支持细微指针景深与纸面光泽反馈
- 成果数字进入视口时递增，页头同步显示阅读进度与章节编号
- 视觉作品灯箱支持上一张 / 下一张、方向键与 `Esc` 关闭
- 游戏品类支持方向键切换，并为详情、清单与海报提供连续转场
- Vibe Coding Lab 支持一键载入示例、链路阶段反馈与结果生成信号
- 证据抽屉自动管理焦点并支持键盘关闭

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认通常为 `http://127.0.0.1:5173/`。

## 生产构建

```bash
npm run build
```

可部署文件会生成在 `dist/`，可以直接交给 Vercel、Netlify 或其他静态托管平台。

`main` 分支已连接 Vercel Git 集成：推送到 `main` 会自动更新生产站，其他分支与 Pull Request 会生成独立预览部署。

## 项目结构

```text
src/
  components/        页面模块与交互组件
  data/              项目、指标、游戏品类与导航数据
  hooks/             当前章节与滚动状态
  styles.css         完整视觉系统与响应式规则
public/
  assets/            绘画、摄影、数据截图与 zine 海报
  downloads/         可下载的作品集与简历 PDF
design/concepts/     本次实现采用的三张视觉概念图
```
